std::optional< MemoryUsage > ww4_utils::MemoryUtils::captureMemoryUsage ( )
staticnoexcept

Captures the current memory usage of the calling process.

Reads metrics from /proc/self/status on Linux systems.

Returns
A MemoryUsage struct containing the captured metrics, or std::nullopt if capture fails.
Precondition
The operating system must provide /proc/self/status (Linux).

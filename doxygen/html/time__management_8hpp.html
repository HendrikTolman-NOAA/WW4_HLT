Detailed Description

Routines for management of date and time. 

  +--------------------------------------------------------+
  | WAVEWATCH IV, open source, code management by NOAA/NWS |
  +--------------------------------------------------------+

This header defines the DateTime structure and TimeManagement class, providing utilities for calendar calculations, time increments, and conversions between various time formats including YYYYMMDD/HHMMSS, DateArray (8-integer array), and Julian Days.

Detailed Description

Routines for management of date and time, converted from WW3 w3timemd.F90.

Provides static methods for time arithmetic, calendar conversions, and high-precision profiling. Supports multiple calendar systems: Standard (Gregorian), NoLeap (365-day), and ThreeSixtyDay.
